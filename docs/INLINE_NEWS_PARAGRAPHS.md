# Цельные абзацы вместо отдельных заголовков

2026-10-15: каждая новость публикуется одним связным абзацем с жирной
ключевой фразой в начале первого предложения. Три отдельные строки заголовков
и пустые строки между заголовком и текстом больше не добавляются.
Общий заголовок выпуска, номера, разделители, подписка и trailer-ссылки сохраняются.

Цель всего Markdown-выпуска — 920–960 символов, включая служебные элементы
и добавляемые Python ссылки трейлеров. Жёсткий project limit остаётся 1000,
лимит Telegram caption — 1024. При недостатке исходных фактов допустим более
короткий выпуск; неподтверждённые детали и вода ради длины запрещены.

Вместо прежних 190–205 символов основной текст теперь ориентируется на
260–275 символов на полный абзац (max 300). Это ориентир: место распределяется
по фактуре, с приоритетом общего бюджета и длины реальных trailer-строк.
Прежний дополнительный вычет 120 символов на трейлер убран из всех трёх
редакторских инструкций, чтобы не занижать фактическую целевую длину.

Совместимость с БД: JSON/items сохраняют историческое поле headline; теперь
оно содержит начальную ключевую фразу без Markdown. Body содержит полный
абзац, уже начинающийся с этой фразы. Builder выделяет совпадающий префикс
жирным и не дублирует его. Старые items с раздельным headline/body поддерживаются
при сборке, а сохранённые post_text и опубликованные сообщения не переписываются.
Миграция БД не требуется. Подход использует существующую строгую JSON-схему
с уточнёнными descriptions: [OpenAI Docs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).

Изменены generation, self-review и editorial revision; generator v10,
primary prompt v8, revision prompt v6. Новый request key отделяет новый формат
от прошлых попыток. Прежняя защита незавершённого длинного текста сохранена
независимо от нового целевого объёма. Расписание и модели не меняются.

Проверки выполняются на cloud-001 из GitHub snapshot, без платных вызовов
и без Telegram отправки. Реальную стилистику оцениваем на следующем выпуске.
