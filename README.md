# TOP 3 NEWS — Telegram-бот киноновостей

Telegram-бот для автоматизированного поиска, анализа, подготовки и публикации трёх главных киноновостей дня.

Основные интеллектуальные этапы выполняет OpenAI-агент, работающий через API OpenAI:

* поиск актуальной информации в настроенных источниках;
* извлечение и проверка фактов;
* очистка, нормализация и дедупликация материалов;
* анализ каждой новости по формуле из 16 параметров с весами;
* ранжирование кандидатов и выбор TOP-3;
* генерация текста публикации;
* форматирование текста для Telegram;
* генерация единой PNG-иллюстрации для трёх новостей;
* подготовка публикации к отправке по расписанию.

Фактическую отправку сообщения в Telegram-канал выполняет приложение через Telegram Bot API.

На этапе MVP публикация возможна только после подтверждения человеком. После стабилизации системы планируется добавить независимую проверку подготовленного поста другой AI-моделью и перейти к безопасной автоматической публикации по расписанию.

## Оценка и выбор TOP-3

Каждая новость анализируется OpenAI-агентом по 16 содержательным параметрам. Для каждого параметра задаётся собственный вес.

Версии формулы, параметров, модели и промпта должны фиксироваться, чтобы каждый запуск ранжирования можно было воспроизвести и проверить.

В текущей модели используется итоговый индивидуальный балл новости:

```text
B_i = 0.20 × F_i
    + 0.30 × M_i
    + 0.20 × R_i
    + 0.15 × (H_i × Q_i)
```

Где:

* `F` — свежесть и актуальность новости;
* `M` — масштаб события и потенциальный охват;
* `R` — общественный резонанс и вовлечённость аудитории;
* `H` — скандальность, необычность или другой цепляющий элемент;
* `Q` — подтверждённость информации и качество источников.

Для отбора используются только новости из установленного временного окна, как правило за последние 24 часа.

После индивидуального ранжирования применяется фильтр разнообразия: итоговая тройка не должна состоять из трёх однотипных новостей, например только из сообщений о кассовых сборах.

Для каждой оценки сохраняются:

* значения компонентов формулы;
* итоговый балл;
* позиция в рейтинге;
* признак допуска к отбору;
* причина исключения;
* текстовое объяснение оценки;
* дополнительные структурированные данные анализа.

## Роль OpenAI-агента

OpenAI-агент управляет интеллектуальным сценарием подготовки ежедневной публикации.

Он должен:

1. Найти актуальные новости в разрешённых источниках.
2. Выделить исходные факты, даты, имена, названия и ссылки.
3. Сопоставить сообщения из разных источников.
4. Исключить дубли и слабоподтверждённые материалы.
5. Оценить новости по 16 параметрам с установленными весами.
6. Выбрать три наиболее значимые и при этом разнообразные темы.
7. Подготовить текст своими словами без копирования исходных публикаций.
8. Добавить проверяемые ссылки на первичные или официальные источники.
9. Отформатировать публикацию для Telegram.
10. Создать промпт и сгенерировать единую PNG-иллюстрацию.
11. Передать подготовленный пост на независимую AI-проверку.
12. Подготовить публикацию к ручному подтверждению или автоматической отправке по расписанию.

Все значимые результаты работы агента должны сохраняться в PostgreSQL: найденные материалы, оценки, выбранные новости, версии промптов, сгенерированные тексты, изображения, результаты проверок и попытки публикации.

## Подтверждение публикации

На этапе MVP бот отправляет подготовленный пост ответственному пользователю и предоставляет действия:

* опубликовать;
* перегенерировать текст;
* перегенерировать изображение;
* заменить одну из новостей;
* отклонить публикацию.

Решение пользователя и все выполненные действия сохраняются в PostgreSQL.

## Независимая AI-проверка

После генерации поста будет выполняться проверка отдельной AI-моделью-рецензентом.

Модель-рецензент должна проверять:

* соответствие текста исходным материалам;
* наличие неподтверждённых утверждений;
* точность имён, дат, названий и числовых данных;
* корректность ссылок и источников;
* дублирование новостей;
* соответствие выбранных новостей правилам TOP-3;
* соблюдение фильтра разнообразия;
* качество заголовков и текста;
* правильность Telegram-форматирования;
* согласованность текста и изображения;
* пригодность публикации без ручного редактирования.

Результат проверки возвращается в структурированном виде:

* итоговое решение;
* перечень найденных проблем;
* рекомендуемое действие;
* оценки по отдельным критериям;
* итоговая уверенность модели;
* признак необходимости ручной проверки.

На первых этапах AI-рецензент не может самостоятельно разрешать публикацию. Его вывод сравнивается с решением человека.

Автоматическая публикация будет разрешена только после накопления достаточной статистики и подтверждения надёжности независимой проверки.

## Публикация по расписанию

Приложение должно запускать ежедневный сценарий по установленному расписанию.

OpenAI-агент выполняет поиск, анализ, выбор новостей и генерацию материалов. После получения разрешения на публикацию приложение отправляет готовый текст и изображение в Telegram-канал через Telegram Bot API.

Для каждой попытки публикации сохраняются:

* запланированное время;
* фактическое время запуска;
* идентификатор подготовленного поста;
* идентификатор Telegram-сообщения;
* статус отправки;
* ответ Telegram API;
* код и описание ошибки;
* номер повторной попытки.
