# TOP 3 NEWS — Telegram-бот киноновостей

Telegram-бот для автоматизированного сбора, оценки, подготовки и публикации трёх главных киноновостей дня.

На первом этапе публикация выполняется только после подтверждения человеком. В дальнейшем планируется добавить независимую проверку подготовленного поста другой AI-моделью и постепенно перейти к безопасной автоматической публикации.

## Основной сценарий MVP

```text
Источники киноновостей
        ↓
Сбор новостей
        ↓
Очистка и нормализация
        ↓
Дедупликация
        ↓
Оценка и ранжирование
        ↓
Выбор TOP-3
        ↓
Генерация текста публикации
        ↓
Генерация общей PNG-иллюстрации
        ↓
Предпросмотр в Telegram
        ↓
Подтверждение человеком
        ↓
Публикация в Telegram-канале
```

## Подтверждение публикации

На этапе MVP бот должен отправлять подготовленный пост ответственному пользователю и предоставлять действия:

* опубликовать;
* перегенерировать текст;
* перегенерировать изображение;
* заменить одну из новостей;
* отклонить публикацию.

Без явного подтверждения человека пост не публикуется.

## Статусы публикации

Предполагаемый жизненный цикл:

```text
draft
collected
ranked
generated
awaiting_review
approved
rejected
published
failed
```

## Будущая AI-проверка

После стабилизации MVP между генерацией поста и подтверждением человеком будет добавлена независимая модель-рецензент.

Она должна проверять:

* соответствие текста исходным материалам;
* наличие неподтверждённых утверждений;
* корректность ссылок и источников;
* дублирование новостей;
* соответствие выбранных новостей правилам TOP-3;
* качество заголовков и текста;
* пригодность публикации без ручного редактирования.

Результат проверки должен возвращаться в структурированном виде с итоговым решением, перечнем найденных проблем и оценкой уверенности.

На первых этапах AI-рецензент не сможет самостоятельно разрешать публикацию. Его вывод будет сравниваться с решениями человека.

## Структура проекта

```text
top3-news-bot/
├── app/
│   ├── bot/            # Telegram-интерфейс и обработчики команд
│   ├── collectors/     # Получение новостей из источников
│   ├── db/             # Работа с PostgreSQL
│   ├── generation/     # Генерация текста и изображений
│   ├── publication/    # Подготовка и публикация постов
│   ├── ranking/        # Оценка и выбор TOP-3
│   └── review/         # Ручная и AI-проверка
├── config/             # Конфигурационные файлы
├── data/
│   └── images/         # Временные и итоговые изображения
├── logs/               # Логи приложения
├── migrations/         # Миграции PostgreSQL
├── prompts/            # Версионируемые промпты AI-моделей
├── scripts/            # Служебные скрипты
├── tests/              # Автоматические тесты
├── .python-version
├── pyproject.toml
└── uv.lock
```

## План разработки

1. Зафиксировать структуру проекта.
2. Спроектировать модель данных PostgreSQL.
3. Создать Telegram-бота через BotFather.
4. Подключить бот к тестовому приватному чату или каналу.
5. Реализовать сохранение публикаций и их статусов.
6. Реализовать предпросмотр и ручное подтверждение.
7. Подключить сбор источников новостей.
8. Реализовать очистку и дедупликацию.
9. Реализовать оценку и выбор TOP-3.
10. Подключить генерацию текста.
11. Подключить генерацию общей PNG-иллюстрации.
12. Реализовать публикацию в Telegram-канале.
13. Добавить независимую AI-проверку.
14. Настроить GitHub и автоматический деплой на `cloud-001`.
15. Настроить запуск, логирование, мониторинг и резервное копирование.
